# Every crate name that may appear in Cargo.lock.
#
# The denylist in ci/check-net-deps.sh asks "is this one of the crates we know
# opens sockets?", which is a question only answerable about crates somebody
# already thought of. A crate that is new, renamed, or simply never considered
# passes it — and the script's own comment concedes as much.
#
# This asks the answerable question instead: did a human look at this crate at
# all? Anything in the lockfile that is not named here fails the build, so a
# new dependency — direct or transitive, socket-capable or not — cannot arrive
# without an edit to this file in the same commit, next to the DEPENDENCIES.md
# entry that says why it is here. The denylist stays as the fast, specific
# check it is; this is the one that holds for crates nobody thought to name.
#
# Regenerate deliberately, never reflexively:
#   sed -n 's/^name = "\(.*\)"$/\1/p' Cargo.lock | sort -u
#
# One name per line. Blank lines and # comments are ignored.
